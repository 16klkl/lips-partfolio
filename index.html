Goals

My goal is to become a skilled Full-Stack Web Developer with a strong foundation in both frontend and backend technologies, and then gradually transition into the field of Machine Learning.

To achieve this, I’ve created a clear and structured 6-month roadmap:

Months 1–2: I start by learning the fundamentals — HTML, CSS, Git, and GitHub — and create a portfolio site with a contact form. Then I dive into JavaScript basics and DOM manipulation, building an interactive webpage.

Months 2–3: I deepen my understanding of JavaScript and learn React, applying it in a To-Do or movie website. Then I work with React Router, Tailwind CSS, and external APIs, creating a React app that fetches data from external services.

Months 3–4: I switch focus to backend development — learning Python, FastAPI, and SQL — and build a backend project with a database. I then move on to JWT authentication, SQLAlchemy, and frontend APIs, building a blog or task manager. After that, I integrate Axios, user authentication, and basic Docker, resulting in a full-stack application.

Months 4–5: I learn how to deploy frontend and backend apps using Vercel and Render. Then I begin working with Python for data analysis, using pandas and matplotlib to create charts and analyze data.

Months 5–6: I dive into Machine Learning, starting with scikit-learn and ML algorithms, and build an ML model for prediction. I then integrate this model into FastAPI to create an ML-powered API, and finally combine it with a frontend to build a full AI web application for text analysis.

This roadmap reflects my commitment to mastering modern web technologies and building a strong base in AI. My long-term goal is to become a creative and confident developer capable of building useful, real-world applications and eventually entering the field of Artificial Intelligence.
